# 베리맵을 업그레이드된 베리업에 합치는 법

작성 2026-10-22. 베리맵 작업분을 다른 사람이 작업한 베리업에 올릴 때 이 문서대로 하면 된다.

## 요약

베리맵은 거의 전부 **새 파일**이라 베리업과 이름이 겹치지 않는다.
공유하는 파일은 아래 **4개뿐**이고, 그중 3개는 블록을 덧붙인 것이라 다시 넣기 쉽다.

---

## 1. 그대로 복사하면 되는 것 (충돌 없음)

| 경로 | 내용 |
|---|---|
| `scripts/verimap_load_codetable.mjs` | 코드표 불러오기·정규화 |
| `scripts/verimap_collect_coupang.mjs` | 쿠팡 수집 |
| `scripts/verimap_collect_naver.mjs` | 스마트스토어 수집 (Electron 필요) |
| `scripts/verimap_collect_imweb.mjs` | 아임웹 상품·옵션 수집 |
| `scripts/verimap_match.mjs` | 대조 |
| `src/ui/index_verimap.html` | 베리맵 창 |
| `data/verimap/` | 설정·사전·수집결과 전부 |

`data/verimap/` 안에서 **다시 만들 수 없는 것**은 이 7개다. 나머지는 버튼으로 재생성된다.

```
config.json          코드표 시트 주소·gid
model_names.json     다국어 표기 시트에서 뽑은 모델명 사전(일문 625개)
model_aliases.json   모델명 별칭
part_aliases.json    구 번호 → 현행 번호
verimap_links.json   채널별 링크 주소 틀
manual_links.json    손으로 확인한 표시
verimap_ui.json      직원 계정 아이디·칸 폭 (개인 설정, 안 넘겨도 됨)
```

캐시 3개(`coupang_detail_cache.json`, `imweb_options_cache.json`, `imweb_options_cache_b2b.json`)는
없어도 되지만 같이 주면 첫 수집 시간이 20분쯤 줄어든다.

## 2. 베리업 파일을 고친 곳 (여기만 확인하면 된다)

### src/ui/launcher.html — 베리맵 카드
`launchMap()` 함수와 카드 버튼 한 블록. 다른 카드들 옆에 그대로 끼워 넣으면 된다.

```html
<!-- 베리맵 카드 -->
<button class="app-card map-card" onclick="launchMap()"> … <h2>베리맵</h2> … </button>
```
```js
function launchMap() { ipcRenderer.send('launch-app', 'map'); }
```

### src/ui/launcher.css — 보라색 테마
`--map-primary: #8b5cf6;` 한 줄과 `.map-card` / `.map-icon` 규칙 6줄. 파일 끝에 붙여도 된다.

### src/main_process.js — 창 띄우기 (5곳)
1. `let mapWindow;` 선언 추가
2. `createMapWindow()` 함수 추가 — `ui/index_verimap.html` 을 1100x780 으로 연다
3. `launch-app` 처리에 `else if (appName === 'map') createMapWindow();` 추가
4. `liveWindows()` 가 돌려주는 배열에 `mapWindow` 추가
5. 런처 창 높이 `480` → `560` (카드가 하나 늘어서)

### src/platforms/openapi/imweb_client.js — 토큰 갱신 수정 ⚠
**이 파일만 주의가 필요하다.** git 이 추적하지 않는 파일이라(커밋 안 됨) 양쪽 수정이 조용히 덮일 수 있다.

고친 내용: 아임웹이 refreshToken 을 거부하는 사이트(오류 30170)에서 매번
"갱신 시도 → 실패 → 새로 발급" 으로 두 번 부르던 것을, 한 번 거부당하면 그 세션에서는
갱신을 건너뛰고 바로 발급하도록 바꿨다. 호출 수가 절반으로 준다.

```js
let refreshUsable = true;            // ← 추가
…
if (refreshUsable && current?.refreshToken && current.clientId === clientId) {
  try { … } catch (error) {
    if (String(error.errorCode) === '30170') {
      refreshUsable = false;         // ← 추가
      log('[아임웹 API] 이 사이트는 토큰 갱신을 받지 않습니다(30170) — 이후로는 바로 발급합니다');
    } else { … }
  }
}
```

## 3. 베리업 쪽에서 **읽기만** 하는 것 (고치지 않았다)

베리맵은 아래를 불러다 쓰기만 한다. 베리업이 바뀌어도 함수 이름과 돌려주는 모양만 같으면 된다.

- `src/platforms/coupang_api.js` — `CoupangAPI`
- `src/platforms/naver_store.js`, `naver_api.js` — `NaverStore`, `NaverAPI`
- `src/utils/server_keys.js` — `serverLogin` · `fetchCredentials`
- `src/platforms/openapi/imweb_client.js` — `createImwebSession` · `createImwebClient`
- `src/platforms/openapi/imweb_oauth.js` — `oauthCredentialsFromConfig`
- `src/utils/runtime_proxy.js` — 관리자 서버 경유

**이 중 하나라도 이름이나 반환 모양이 바뀌면 베리맵이 깨진다.** 합친 뒤 베리맵에서
1 → 3 → 11 → 21 순서로 한 번 돌려 보면 바로 드러난다.

---

## 4. 합치는 순서 (권장)

1. 지금 상태가 detached HEAD 다. 먼저 브랜치를 따서 커밋해 둔다.
   `git switch -c verimap` → `git add -A` → `git commit -m "베리맵"`
2. 상대방의 베리업을 받아 별도 브랜치로 둔다.
3. 1항의 새 파일·폴더를 복사한다 (충돌 없음).
4. 2항의 4개 파일에 베리맵 변경분을 다시 넣는다.
5. 베리맵 창을 열어 1·3·11·21 을 돌려 본다. 숫자가 전과 비슷하면 성공이다.

## 5. 넘기면 안 되는 것

인증키는 `data/verimap/` 에 없다. 아임웹 OAuth 키는
`%APPDATA%\very-up-ver2\` 에, 네이버 키는 윈도 암호화 저장소에 있다.
받는 사람은 자기 계정으로 새로 넣어야 한다.
