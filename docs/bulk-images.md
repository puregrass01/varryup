# 상품 일괄 수정 — 이미지

아임웹 B2B·본사·영문·일본은 현재 `data/vehicle_catalog.json`만 참조합니다.
차량 variants와 SKU listings를 연결하며, 쿠팡 상품번호는 가져오지 않습니다.
카탈로그 USD 참고가는 실제 현재 판매가가 아닙니다. 없는 가격·이미지는 임의로 채우지 않습니다.
아임웹 목록·상세 조회에는 외부 요청이 없으며 API 연동 전까지 가격·이미지 저장은 비활성화됩니다.
검색·필터·CSV 내보내기는 사용할 수 있습니다. 향후 API 데이터 공급원은 `src/utils/imweb_catalog.js`의 반환 구조를 기준으로 교체할 수 있습니다.

사진 열의 공통 입력칸에 `https://…/1.jpg|https://…/2.jpg` 또는 ESM `<img src="…">` HTML을 입력합니다. 빈칸이면 이미지 설정의 선택된 ESM 상세 이미지 목록을 사용합니다(대표 이미지 자동 업로드 없음).
상품 선택 → 이미지 불러오기 → 선택 변경 저장 순서입니다. 기존 이미지와 변경 확인값은 필요할 때 자동으로 조회합니다.
이미지 불러오기는 ESM 이미지 응답을 확인하고 선택한 상품의 변경안을 만듭니다. 실제 쇼핑몰 전송은 선택 변경 저장에서만 수행합니다.
머리글 전체선택은 현재 필터에 맞는 모든 페이지의 수정 가능한 행에 적용됩니다. 필터 밖의 선택 상품은 저장 대상에서 제외되며, 다른 페이지에 있는 선택 상품은 포함됩니다.
가격 필터는 전체 조회 데이터의 가격으로 동적으로 구성하며 현재가 조회·저장 후 갱신됩니다. 아임웹은 카탈로그 USD 참고가를 사용하고, 가격이 없는 행은 별도로 표시합니다.

| 플랫폼 | 사진 표시 | 저장 대상 |
| --- | --- | --- |
| 네이버·쿠팡 | 순서가 표시된 img 미리보기 | 상세 이미지 전체 목록 |
| 아임웹 B2B·본사·영문·일본 | 카탈로그에 이미지 없음 | 현재 참조 전용 |
| 아마존 미국·일본 | 이미지 미리보기 + 파이프로 구분한 URL 목록 | 대표 + 추가 이미지 (이 앱은 최대 9장) |
| eBay | 이미지 미리보기 + 파이프로 구분한 URL 목록 | 상품 이미지 (최대 24장) |

이 구분은 이 앱의 저장 대상 필드를 기준으로 합니다. eBay 설명 전체가 HTML을 지원하지 않는다는 뜻은 아닙니다.
아마존·eBay는 첫 번째 URL이 대표 이미지입니다. 입력 목록은 전체 교체이며, 아마존의 남는 이미지 슬롯도 제거합니다.
국내 상세 이미지 수정은 별도의 대표 이미지를 바꾸지 않습니다.
쿠팡은 옵션 행이 여러 개여도 상품당 한 번만 이미지 요청을 보내고 모든 옵션의 상세 이미지에 적용합니다. 이 수정은 쿠팡 승인 대상입니다.

썸네일이나 URL을 클릭하면 확대 창이 열립니다. 긴 이미지 전체를 스크롤할 수 있고, 원본 크기 전환·닫기·Esc를 지원합니다.

ESM URL은 불러올 때와 저장 직전에 HTTPS 응답 상태 및 image/* Content-Type을 확인합니다. URL 순서와 버전 쿼리는 유지합니다.
동일 URL 파일을 덮어썼다면 새 버전 URL을 입력하세요. 이 화면은 ESM 원본 파일을 수정하거나 임의 버전값을 붙이지 않습니다.
현재 이미지가 조회 이후 달라지면 쓰기를 중단합니다. 일반 저장은 재조회로 확인하며, 아마존 접수는 반영 완료와 별도로 표시합니다.
가격과 이미지는 별도 요청으로 처리되므로 결과도 따로 표시하며, CSV에 두 결과와 URL 목록을 포함합니다. 일부 반영 또는 결과 불명 시 다시 불러와 확인합니다.
