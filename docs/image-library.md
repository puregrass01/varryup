# 이미지 기본 목록과 ESM 호스팅

[img] 이미지의 기본 상세 목록은 앱에 포함된 ESM HTML에서 읽습니다. 로컬 다운로드 폴더나 ESM 로그인·목록 조회 없이 표시됩니다.

| 대상 | 기본 상세 HTML의 ESM 경로 | 상세 이미지 수 | 대표 이미지 |
| --- | --- | --- | --- |
| 네이버·쿠팡·아임웹 | yhshma/기본값/스마트스토어 상세페이지 | 6장 | 기존 공통 대표 사진 |
| Amazon | yhshma/기본값/아마존 영어 번역 | 6장 | VerySeed GLOBAL 최신 사진 |
| eBay | yhshma/기본값/이베이 영어 번역 | 7장 | VerySeed GLOBAL 최신 사진 |

2026-09-28 위 19개 URL 모두 HEAD 응답 200, image/jpeg 확인. 기본 HTML은 src/utils/image_defaults.js에 포함되며, 실행 중 로컬 상세 이미지 폴더를 검색하거나 ESM 폴더 목록을 조회해 만들지 않습니다. 네트워크가 끊겨 미리보기 이미지를 불러오지 못해도 목록은 유지됩니다.

1. 쇼핑몰을 선택하면 대표 사진과 기본 상세 목록이 바로 표시됩니다. Amazon 추가 URL 입력란도 일괄 적용 전부터 채워집니다.
2. 체크를 끄면 제외하고 ↑로 순서를 바꿉니다.
3. HTML 버튼에서 ESM의 <img src="…"> 코드를 넣고 저장할 수 있습니다. 이미지 URL만 추출하며 스크립트·이벤트 속성은 실행하지 않습니다.
   편집기는 목록에 보이는 순서(↑ 반영, 체크 끈 이미지 포함)로 열리고, 저장하면 그 줄 순서가 목록 순서가 됩니다. 체크 해제는 남아 있는 이미지 것만 그대로 둡니다(2026-10-27).
   - ESM 이미지호스팅(Edge)에서 썸네일을 끌어 목록에 놓거나, '주소복사'·'HTML 태그복사' 결과를 목록을 누른 뒤 Ctrl+V로 붙여 넣으면 지금 고른 목록(국내 공통/Amazon/eBay) 끝에 상세 이미지로 붙습니다.
     이미 있는 이미지는 건너뛰고, 체크를 꺼 두었던 이미지는 다시 고릅니다. 대표 행에 놓아도 상세로 붙습니다. `https://ai.esmplus.com` 주소만 받고 http는 https로 바꿉니다.
     끌어 온 마크업은 주소 문자열만 읽고 화면에 넣지 않습니다. HTML 편집기가 열려 있으면 편집 중인 HTML 끝에 넣으니(이미 있는 줄은 건너뜀) 'HTML 저장'을 누르세요.
     편집 칸 안에서 줄을 끌어 옮기거나 ESM 주소가 아닌 글자를 놓는 것은 보통 편집과 같습니다. 일괄 적용·등록 중에는 넣지 않고 안내만 합니다.
   - 상품 일괄 수정의 이미지 주소 칸에 끌어 놓으면 커서 자리에 끼우지 않고 끝에 `|`로 붙입니다(끝에 남은 `|`는 하나로 정리).
   - 한 번에 끄는 것은 한 장입니다. 여러 장은 ESM에서 체크한 뒤 'HTML 태그복사' → 붙여넣기로 넣습니다. VERY UP을 관리자 권한으로 실행하면 Windows가 Edge에서의 드롭을 막습니다.
4. 기본값 버튼은 상세 HTML, 선택과 순서를 기본 목록으로 복원합니다.
5. 대표 또는 VerySeed 최신으로 상품별 대표 사진을 선택합니다.
6. 일괄 적용 시 기존 ESM 상세 URL의 이미지 응답을 확인하고 재사용합니다. 로컬 대표 사진은 필요할 때만 ESM에 올립니다.

대표 사진은 상품별 자료이므로 기존 선택/VerySeed 생성 방식과 별개입니다. 국내 대표 사진의 기존 로컬 파일 선택 및 네이버 네이티브 파일 업로드는 유지됩니다. 상세 이미지에는 로컬 폴더가 필요하지 않습니다.

신규 등록 시 아직 준비되지 않은 목록은 등록 전에 준비합니다. ESM 주소가 실패하면 등록을 중단하고 목록을 유지합니다. 원격 상세 이미지를 로컬 파일로 대체하거나 재업로드하지 않습니다. 기존 상품 수정에는 기본 목록을 자동 적용하지 않습니다.

상품 수정 폼(네이버·쿠팡·Amazon·eBay·아임웹)의 이미지 타일 끝 [+ ESM 상세]는 로컬 폴더 없이, 일괄 수정과 같은 이미지 설정의 선택된 ESM 상세 이미지(국내·Amazon·eBay 목록)를 목록 끝에 붙입니다. 이미 있는 URL은 건너뜁니다. ←/→로 순서를 바꾸고(Amazon·eBay는 첫 장이 대표) 기존 수정 저장 버튼으로 반영합니다.

## 전송

- Amazon: 대표 URL → main_product_image_locator, 선택한 추가 URL → other_product_image_locator_1~8. HTML 자체가 아닌 img의 src URL을 JSON으로 전송합니다.
- eBay: 대표를 첫 번째에 둔 product.imageUrls, 최대 24장.
- 쿠팡·아임웹: 대표 URL과 선택 상세 HTML을 구분해 전달합니다.
- 네이버: 기존 판매자센터 신규 복사등록 흐름에서 대표 파일과 ESM 상세 HTML을 사용합니다.

## 저장과 이전 설정

- image-library.json에 사용자 HTML, 제외/순서, 대표 선택 및 업로드 URL을 저장합니다.
- 이전 버전의 로컬 상세 폴더 설정만 있는 경우 ESM 기본 HTML을 사용합니다.
- 로컬 폴더 읽기는 명시적인 내부 호환 옵션으로만 남아 있으며, 기본 목록과 현재 상세 이미지 UI는 ESM HTML을 사용합니다.
- 대표 업로드 파일은 vu_<SHA256> 이름을 사용해 이전 상품의 사진을 덮어쓰지 않습니다.
