# 아임웹 영문몰 · 최신 환율 일괄 업로드 전략

## 적용된 범위 (2026-09-29)

대상: https://optic-glass-us.imweb.me/ 의 영문 게시판. 관리자 주소는 동일 사이트의 /admin으로 고정합니다.
현재 코드에 적용했으며, 이번 작업에서 운영 게시글을 새로 게시하거나 수정하지 않았습니다.

- 신규등록: 기존 Excel 카탈로그에서 선택한 USD 판매가를 영문 게시판 입력란으로 전달합니다. 숫자의 크기로 원화/달러를 추측하지 않습니다.
- 게시글 본문에는 'Price (USD): $109.32' 형태의 가격 문구를 넣고, 그 문구의 툴팁에만 USD·JPY·KRW 환산 금액을 표시합니다. 별도 환율표는 없습니다.
- 상품수정: 선택한 영문 게시글을 API로 불러오면 이 기능으로 저장한 USD 판매가를 표시합니다. 값을 입력하고 수정하면 관리용 표시가 있는 가격 문구만 교체하며, 빈 값은 기존 가격 문구를 유지합니다. 과거 글의 임의 숫자·가격은 자동 추출/덮어쓰기하지 않습니다.
- 수정 화면의 판매가 툴팁은 불러온 값이나 현재 입력값을 기준으로 계산합니다.
- 한 상품을 여러 쇼핑몰에 올리는 기존 일괄 등록에서 영문 자사몰이 선택되면, 첫 전송 전에 USD 가격과 환율을 한 번 확정합니다. 진행 중 환율 조회가 갱신돼도 영문 게시판에 전달할 가격·환율은 유지합니다.
- 일괄 등록은 환율이 없거나 수집 후 24시간 이상 지난 경우 시작하지 않습니다. 단독 영문 등록·가격수정도 메인 프로세스에서 같은 검증을 수행합니다.
- 서버는 yfinance로 환율을 수집하고 24시간 캐시합니다. 휴일의 시세 기준일과 수집 시각은 구분합니다.
- 이미 게시된 글의 툴팁은 등록·수정 당시 환율입니다. 일일 서버 환율 갱신이 기존 게시글을 자동으로 다시 쓰지는 않습니다.
- 국내 B2B 결제 가격과 한국어·일본어 게시글에는 영문 가격 문구를 추가하지 않습니다. 다른 몰의 확정 USD 판매가는 그대로 사용합니다.

## 사용 및 검증

1. 베리업3를 완전히 종료한 뒤 다시 실행합니다. 메인 프로세스를 다시 실행해야 currency-rates-get 핸들러가 등록됩니다.
2. 신규등록에서 USA 자사몰을 선택하고 기존 Excel SKU/판매가를 확인합니다. 영문 게시판 탭의 판매가(USD)에도 같은 값이 채워집니다.
3. 판매가에 마우스를 올려 환산값을 확인하고 기존 등록 버튼 또는 일괄 등록 버튼을 사용합니다.
4. 상품수정에서는 영문 게시글을 검색·불러온 뒤 판매가를 입력하고 수정합니다. 기존 관리 가격이 없는 글은 판매가를 직접 입력해야 합니다.

환율 계산·검증, 영문 사이트 라우팅, 게시판 API 전송 본문, 수정 시 문구 보존, 브라우저 툴팁과 배치 환율 고정,
실제 Electron IPC 호출을 로컬 테스트로 검증합니다. 아임웹 운영 서버가 HTML title 및 관리용 data-* 속성을
보존하는지는 실제 대상 게시글 저장 후 확인해야 합니다. 수정 경로는 저장 후 재조회하여 USD 가격 반영을 검사합니다.

## 여러 Excel 행으로 확장할 때의 후속 설계

아래 항목은 다중 상품 업로드·재개를 위한 후속 설계이며, 현재 구현된 기능으로 간주하지 않습니다.
기존 일괄 등록은 한 상품→여러 쇼핑몰입니다. 실행 종료 후 다시 누르면 새 환율을 확정하며,
현재 배치 스냅샷은 메모리에만 보관합니다. 앱 재시작 후 같은 배치를 재개하는 기능은 아래 저장 구조가 필요합니다.

## 가격 원본 규칙

1. 각 행을 사이트, SKU/상품 ID, 옵션 ID로 식별합니다. 브랜드·차종명만으로 가격을 연결하지 않습니다.
2. 원본에 `sourceAmount`, `sourceCurrency`, `sourceType`(Excel/API), 파일·시트·행 또는 API 상품 ID, 원본 조회 시각을 기록합니다.
3. 수정 작업은 선택한 상품·옵션의 API 가격을 우선합니다. API 조회 실패 시 오래된 엑셀 값으로 자동 대체하지 않습니다.
4. 신규 작업은 사용자가 선택한 엑셀 행의 금액과 명시된 통화를 사용합니다. 숫자의 크기로 원/달러를 추측하지 않습니다.
5. 엑셀에 이미 확정 USD 판매가가 있으면 그대로 사용합니다. 최신 환율로 다시 계산할 대상은 원화 등 다른 통화의 기준 가격입니다.
6. 세트/개별/BSA 옵션, 추가금액, 회원등급 가격은 분리합니다. 기본 판매가에 추가금액을 더하는 방식과 옵션 총액 방식을 먼저 확인합니다.
7. 원본 금액은 보존합니다. 환산한 USD를 다음 실행에서 다시 원화로 취급하는 이중 환산을 방지합니다.

## 환율 확정과 계산

- 배치 준비 시 서버에서 최신 캐시를 조회합니다. 수집 시각이 24시간을 넘거나 미래 시각·0·음수·NaN 환율이면 시작하지 않습니다.
- 시세 기준일과 수집 시각을 구분해 기록합니다. 휴일에는 시세 기준일이 이전 거래일일 수 있습니다.
- `rateSnapshotId`, USD 기준 JPY·KRW 환율, 데이터 출처, 시세 기준일, 수집 시각을 배치에 한 번 저장합니다.
- 미리보기에서 사용한 환율을 실제 전송과 같은 배치의 재시도에도 그대로 사용합니다. 업로드 도중 일일 갱신이 일어나도 배치 가격을 바꾸지 않습니다.
- 환산식: `대상금액 = 원본금액 / rates[sourceCurrency] * rates[targetCurrency]`.
- USD 판매가는 십진수 기준으로 계산한 뒤 마지막 단계에서 센트 단위로 반올림합니다. 환율 자체를 먼저 반올림하지 않습니다.
- 할인·마진·배송비·세금은 별도 가격 정책으로 다룹니다. 요청 없이 환율 계산에 추가하지 않습니다.
- 배치가 장시간 중단되어 재개 시 환율 수집 후 24시간을 넘었으면 미전송 행을 새 배치로 분리해 최신 환율 미리보기를 다시 만듭니다. 이미 성공한 행은 다시 계산하거나 전송하지 않습니다.

## 실행 순서

1. **원본 수집:** 선택한 엑셀 행 또는 API 상품·옵션을 읽고 통화와 금액을 검증합니다.
2. **대상 대조:** 영문 사이트와 상품·옵션 매핑, 신규/수정 구분, 중복 여부를 확인합니다.
3. **환율 확정:** 유효한 환율 스냅샷을 배치에 저장합니다.
4. **미리보기:** 기존 판매가, 원본 가격, 적용할 USD 가격, 차이, 적용 환율을 파일로 내보냅니다. 일반 등록 화면에는 별도 환율표를 추가하지 않고 기존 판매가 툴팁을 유지합니다.
5. **소량 검증:** 소수 상품으로 전송→재조회가 맞는지 확인한 뒤 같은 로직으로 나머지를 처리합니다.
6. **순차 전송:** 확인된 API 제한에 맞춰 처리합니다. 429·일시적 서버 오류는 대기 후 제한적으로 재시도하고, 인증·검증 오류는 해당 범위에서 중단합니다.
7. **결과 재조회:** 서버가 저장한 통화·금액·상품 ID를 확인해야 성공으로 기록합니다.
8. **실패만 재개:** 성공 행을 제외하고 실패·미전송 행만 재개합니다. 응답 시간 초과는 성공 여부가 불명확하므로 조회로 먼저 확인합니다.

실제 업로드 버튼은 계산된 가격이 검토된 배치에만 작동하게 합니다.
한 상품을 여러 몰에 올리는 기존 버튼에 연결할 때도 호출 전 준비 단계에서 환율을 확정하고 각 몰에 같은 스냅샷을 전달합니다.
엑셀 여러 상품을 처리할 때는 별도의 행 단위 작업 목록이 필요합니다.

## 배치 기록

배치에는 다음 항목을 저장합니다.

- 배치 ID, 작업 종류, 대상 사이트 ID, 생성·시작·완료 시각
- 환율 스냅샷과 가격 계산 정책 버전
- 행 ID, 원본 파일/시트/행 또는 API 상품 ID, SKU, 옵션 ID
- 원본 금액·통화, 기존 판매가, 환산 USD 판매가
- 상태: 준비 / 전송 중 / 성공 / 실패 / 결과 확인 필요 / 건너뜀
- 시도 횟수, 대상 상품 ID, 오류 요약, 서버 재조회 결과

기존 등록 원장(`registration_ledger.json`)의 중복 검사를 유지하되 배치 행 기록은 별도로 둡니다.
수정 전 가격은 복구용으로 보관합니다. 되돌리기는 해당 배치가 기록한 상품·옵션에 한정하고, 이후 다른 변경이 있으면 자동 덮어쓰지 않습니다.

## 구현 순서와 검증

1. 확인된 영문 사이트용 어댑터를 다중 상품 업로드에 연결합니다. 국내 B2B 사이트 상수·설정을 공유하지 않습니다.
2. 원본 정규화와 순수 가격 계산 함수를 구현합니다. 외부 쓰기 없이 미리보기를 생성합니다.
3. 배치 스냅샷·행 상태·재시도 저장을 구현합니다.
4. 기존 일괄 등록 또는 엑셀 행 목록의 실행 경로에 연결합니다.
5. 대상 사이트의 테스트 상품으로 실제 저장·재조회 후 운영 배치를 실행합니다.

필수 검증: KRW→USD, USD 원본 유지, JPY→USD, 반올림 경계, 옵션 매핑 불일치, 유효기간 초과,
전송 도중 환율 갱신, API 거절, 시간 초과 후 중복 생성 방지, 성공 행 재전송 방지, 배치 재개,
국내 B2B 가격과 관계없는 게시글을 변경하지 않는지 확인.
