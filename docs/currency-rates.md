# 판매가 환산 툴팁

신규등록·상품수정 화면에는 별도 환율표·금액 입력·가격 적용 버튼이 없습니다.
판매가 입력란이나 라벨에 마우스를 올리면 USD·JPY·KRW 환산 금액을 툴팁으로 표시합니다.
아마존·eBay 판매가를 매일 환율로 맞추는 기능은 모드 바 '환율' 탭의 [일일 환율 자동 변경](fx-auto-price.md)입니다.

- 신규등록: 기존 엑셀 카탈로그의 SKU·옵션을 선택해 채워진 ‘판매가 (USD)’ 값을 사용합니다.
- 상품수정: 아마존·eBay API로 불러온 해당 상품의 판매가 입력값을 사용합니다.
- 아마존은 선택된 미국(USD)·일본(JPY) 마켓 통화를 따릅니다.
- 사용자가 가격을 고치면 고친 값을 기준으로 표시합니다. 툴팁은 판매가를 변경하거나 저장하지 않습니다.
- 입력란을 비우거나 잘못된 금액을 입력하면 환산값을 지웁니다.
- 환율은 USD 기준입니다. 환산식은 금액 / 원래 통화의 USD당 환율 × 대상 통화의 USD당 환율입니다.

## 환율 수집

**앱이 Yahoo Finance에서 직접 받습니다(2026-09-30).** 운영 관리 서버에는 `/api/currency-rates`가 배포되지 않아 404가 났고,
서버 배포 대신 프로그램에서 직접 받기로 했습니다. 로그인하지 않아도 됩니다.

- KRW=X·JPY=X 차트 API(`query1`, 막히면 `query2`)의 최근 5거래일 일별 값 중 두 통화에 모두 있는 가장 최근 날짜를 씁니다.
  서버 yfinance와 같은 규칙입니다. 날짜는 거래소(런던) 기준이고, 오늘 값은 장중 값이라 확정 종가가 아닐 수 있습니다.
- 받은 값은 1시간 동안 다시 받지 않고, 받지 못하면 15분 뒤에 다시 시도합니다. 달러/원 500~5,000원, 달러/엔 30~500엔을
  벗어나면 시세 오류로 보고 쓰지 않습니다.
- 앱이 직접 받지 못하면 관리 서버(배포돼 있고 로그인했을 때)에 한 번 더 묻고, 그래도 안 되면 저장해 둔 값을 씁니다.
- 24시간 이상 지난 환율로는 환산 금액을 표시하지 않고 가격도 바꾸지 않습니다.
- 앱 캐시는 userData/currency_rates.json입니다. 코드는 `src/utils/currency_rates.js`입니다.

관리 서버 쪽(`server/currency_rates.py`, `GET /api/currency-rates`, 직원 로그인 토큰)은 보조 경로로 남겨 두었습니다.
서버에 배포하려면 서버 가상환경에서 requirements.txt를 설치한 뒤 관리 서버를 재시작하세요.
재시작하면 로그인해 있는 직원 PC가 모두 다시 로그인해야 합니다. 서버는 단일 worker로 운영합니다.

    python -m pip install -r server/requirements.txt

서버 캐시는 server/currency_rates.json이며 CURRENCY_RATES_CACHE로 경로를 바꿀 수 있습니다.

## IPC 오류

‘No handler registered for currency-rates-get’은 환율 IPC 추가 이전에 실행한 메인 프로세스에서
새 화면만 다시 불러왔을 때 발생합니다. 화면 새로고침으로는 메인 프로세스가 바뀌지 않습니다.
열린 작업을 저장하고 앱을 완전히 종료한 다음 ‘실행.bat’로 다시 실행하세요.
설치본을 쓰면 새 앱 빌드를 설치해야 합니다.

IPC는 창 생성 전에 등록하며, 초기화 실패는 오류 응답으로 처리합니다.
구버전 실행 중에는 내부 예외 문자열 대신 툴팁으로 재시작 안내를 표시합니다.

참고: https://ranaroussi.github.io/yfinance/reference/api/yfinance.download.html

## 환율 경로 검토 및 보완 (2026-09-30)

- 서버가 표시한 `stale`과 경고를 디스크 캐시에 보존합니다. 최근 수집 시각이어도 서버가 만료로 판정한 값은 툴팁·일괄 수정의 환율가·자동 변경에 사용하지 않습니다. 만료 응답은 15분 후 재시도합니다.
- 장중 환율을 사용할 수 있으므로 화면에는 확정 “종가” 대신 “기준”으로 표시합니다.
- 일본 신규 등록·수정은 환산 완료된 `price`(JPY 정수)를 사용합니다. `priceUsd`만 전달하면 중단하며, 두 필드가 함께 있으면 일본 엔화 값을 사용합니다. 이미지·설명만 수정하면 기존 가격을 유지합니다.
- 신규 등록의 카탈로그 USD 가격은 기존 명시 가격입니다. 툴팁은 환산 참고값이며, 일본 신규 판매가는 엔으로 입력합니다. 국내 기준가로 기존 상품 가격을 계산하려면 상품 일괄 수정에서 값 출처 “환율가”로 “가격 적용”을 사용합니다.
